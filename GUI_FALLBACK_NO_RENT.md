# Бесплатная GUI-проверка на другом Windows-компьютере — не на FotoMag

Это резервный вариант, если стандартный Windows runner в GitHub Actions не предоставляет реальный интерактивный рабочий стол.

1. Нужна независимая, уже имеющаяся машина с Windows 10/11 (для Windows Sandbox — Pro/Enterprise/Education с поддержкой виртуализации), не PRODUCTION-WORKSTATION и не VM, работающая на нём. Из существующих подключений такую машину подтвердить пока не удалось.
2. Работать от отдельного тестового пользователя, без FotoMag VPN, облачных дисков, секретов и клиентских данных. Для Windows Sandbox создать эксперимент с отдельной папкой, не монтировать папки рабочей станции.
3. Установить или использовать бесплатные Node.js >=22, Python 3.11 и Git; оригинальный пакет № 4.6 уже содержит Windows x64 `.exe`, составной патч, скрипт 100×2 и пассивный наблюдатель. Не использовать public-CI Go-бинарник: его защитный флаг разрешает работу только в GitHub-hosted Windows.
4. Открыть Notepad, перевести на передний план и **не переключать рабочий стол** во время проверки. Активный GUI сеанс обязателен. Ввести тестовые флаги строго в том независимом окружении, а не системно на FotoMag: `FOTOMAG_ISOLATED_WINDOWS_LAB=YES`, `FOTOMAG_VM_EVIDENCE_SAFE=YES`.
5. Следовать `test/windows/WINDOWS_LAB_RUNBOOK_TZ4_6.md` из оригинального ZIP и последующему анализатору `analyze-lab-evidence-v4.7.py` из пакета № 4.7. Выполнить 100 baseline и 100 patched запусков, одновременно с наблюдателем HWND/PPID и фокуса. Зафиксировать отличия, включая замыкание дочерних процессов и отсутствие скрытых модальных окон.
6. Отдельно испытать Remote MCP на другом тестовом подключении без токенов FotoMag, проверить независимый вход, переподключение и результат интерактивных команд. Остановиться при первой потере доступа, залипании окна или ошибке broker.
7. Загрузить результаты в чат, но не устанавливать патч на FotoMag до отдельного допуска владельца и окончания активной работы Codex.

На Windows Sandbox сеанс обычно интерактивен, но это не автоматически гарантирует соответствие работе рабочего стола FotoMag. Любые результаты нужно оценивать на полноту измерений и подлинность логов.
